Rclone Backup Servidor

Esta es una integración privada de uso personal para almacenar y recuperar copias de seguridad de un servidor propio mediante Google Drive y la herramienta de código abierto rclone.

Finalidad

La aplicación utiliza OAuth de Google para autorizar el acceso a Google Drive con el consentimiento del propietario. No es un servicio de respaldo ofrecido a terceros ni admite registros públicos de usuarios.

Acceso a los datos

La autorización puede permitir leer, crear, modificar y eliminar archivos de Google Drive, según los permisos concedidos. La automatización está prevista para guardar archivos de respaldo en la cuenta autorizada.

Consulta la política de privacidad para conocer el tratamiento de datos.
